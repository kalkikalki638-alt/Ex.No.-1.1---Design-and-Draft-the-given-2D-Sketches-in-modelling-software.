# Ex.No.-1.1-Design and Draft the given 2D Sketches in modelling software.

## AIM

To sketch the given drawing with dimensions using fusion 360 tool.

## REQUIREMENTS

  1. Autodesk fusion 360
  2. Windows 10
  3. 16 GB of RAM (integrated graphics recommend 2 GB or more)
  4. 2.5 Mbps or faster download; 500 Kbps or faster upload 
## PROCEDURE
1.First, open the autodesk Fusion 360 software on the computer. 
2.Cick on  new design to create a new drawing. 
<img width="961" height="772" alt="Screenshot 2026-11-24 131052" src="https://github.com/user-attachments/assets/19c33bd4-e190-4c05-b9da-5e3e9390dd8d" />
3.Select the create sketch option from the toolbar and choose the XY plane.
<img width="912" height="715" alt="Screenshot 2026-11-24 132008" src="https://github.com/user-attachments/assets/d7bb249d-7e25-4805-9ce6-395aae090177" />
4.Select the circle tool and draw the top outer circle with a diameter of 32mm.
<img width="932" height="591" alt="Screenshot 2026-11-24 162315" src="https://github.com/user-attachments/assets/9e88740a-ae9a-4a9a-8b09-1979a43938c6" />
5.Draw another circle of 20mm diameter inside the top circle using the same centre point. 
6.Next,draw two circles on the left and right sides of the drawing using the Circle tool.  
  Give the required dimensions of R10 and R7. 
7.Draw the bottom outer circle with diameter of 20mm and draw an inner circle of 10mm 
  Diameter.
  
8.Use the line tool to draw the required straight lines and reference lines according to the  
  given figure.
<img width="737" height="463" alt="Screenshot 2026-11-24 162719" src="https://github.com/user-attachments/assets/4cb2d2fe-2ef4-418b-9f04-4d9bc4a6831f" />
9. Select the Arc tool and draw the upper connecting curves between the top circle and the  
   Main body. 
10.Given the required radius of R64 to the upper curved portions on both sides. 
11.Draw the lower connecting curves between the side circles and main body using the 
   Arc tool. 
12.Given the required radius dimensions such as R20 and R10 to the curved portions. 
13.Now,draw the middle design using the Arc tool and create the required curved shape as  
   Shown diagram.
14.Draw the central circular pattern with the required dimension of Ø66 and Ø40.
   <img width="737" height="520" alt="Screenshot 2026-11-24 162953" src="https://github.com/user-attachments/assets/a75c5d57-5c47-4219-90ed-c67ded4fdd27" />
 15. Use small acrs  with a radius of R6 to complete the middle decorvative design. 
16. Use the Trim(T) command to remove the unwanted portions of the circles,lines and arcs
<img width="743" height="335" alt="Screenshot 2026-11-24 163053" src="https://github.com/user-attachments/assets/75710ff7-7386-46fe-8b6a-04a7a128ae64" />
17. Use the sketch Dimension (D) command to give the required dimensions to all the circles  
     And  curved portions. 
18.Set the required horizontal and vertical distances as shown in given drawing. 
19.Check all the dimensions carefully and make sure that drawing matches the given 
   Model.
   
20. After completing the drawing,click on finish Sketch to complete the 2D sketch.
<img width="470" height="687" alt="Screenshot 2026-11-24 163316" src="https://github.com/user-attachments/assets/4009713d-97dd-4510-b1ab-002a371617d0" />
21.Finally,click on file-save and enter the file name as EDM EXERCISE 1.1. 
22. The drawing is now completed successfully in autodesk fusion 360.
